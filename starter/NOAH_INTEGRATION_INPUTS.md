# Dados de integração da página com o Noah

Preencha este arquivo no repositório da página antes de iniciar a integração. Um campo ainda desconhecido fica como `PENDENTE`; o agente não deve inventá-lo.

| Campo | Valor |
| --- | --- |
| Briefing visual e funcional | `NOAH_DESIGN_BRIEF.md` |
| Repositório oficial do kit | `https://github.com/manoelcastro/noah-company-kit` |
| SHA completo da revisão instalada | PENDENTE |
| Caminho da skill instalada e data de instalação/atualização | PENDENTE |
| Empresa e contato responsável | PENDENTE |
| ID e slug confirmados no Noah | PENDENTE |
| Estado da reivindicação (`UNCLAIMED`, `PENDING`, `CLAIMED`) | PENDENTE |
| Origem Noah para QA | `https://dev.noahero.com` |
| Origem Noah para produção | PENDENTE |
| URL HTTPS definitiva da página | PENDENTE |
| Hospedagem e configuração de `frame-ancestors` | PENDENTE |
| Versão fixa do SDK | `@noah/company-web@0.6.0` |
| Formato da vitrine | PENDENTE |
| Fonte atual do conteúdo (ex.: `DEMO`, `COMPANY_CATALOG`, `CMS_PUBLISHED`, `MIXED`) | PENDENTE |
| Compra atual (ex.: `QUOTE_ONLY`, `EXISTING_CHECKOUT`, `NOAH_CHECKOUT`) | PENDENTE |
| Data e evidência do teste direto/incorporado | PENDENTE |

Leia a versão do SDK do `package.json` da revisão obtida e atualize o valor acima quando instalar. A origem de QA é uma sugestão inicial: confirme o ambiente solicitado. Slug, claim e capacidades devem ser verificados no Noah. Não preencha valores presumidos para declarar a integração concluída.

Use este registro também na retomada: anote a última verificação de atualização do kit, as mudanças aplicadas e os testes afetados. Instruções novas não atualizam automaticamente o SDK de uma página já publicada.

Esses rótulos são descrições do projeto, não enums de uma API Noah. Registre a fonte real do conteúdo e a jornada comercial existente, sem marcar um catálogo próprio real como demonstração. `CMS_PUBLISHED` e `NOAH_CHECKOUT` só podem ser preenchidos quando os respectivos serviços estiverem implantados e testados. Esta tabela não é uma fonte de segredos. Credenciais, arquivos fiscais e dados de clientes ficam fora do repositório da página.
